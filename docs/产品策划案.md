# 高考择校助手 · 产品策划案

---

## 一、产品定位

**一句话定位：** 不只告诉你能上哪所大学，更让你知道在那所大学生活是什么样的。

**产品愿景：** 成为高考生了解大学真实生活的第一选择。

**核心差异：** 市面上所有择校工具都在做"分数匹配"，而我们解决的是"分数匹配之后"的问题——这所大学到底值不值得去？

---

## 二、用户画像

| 维度 | 描述 |
|------|------|
| 年龄 | 18-19岁 |
| 身份 | 高考毕业生 |
| 痛点 | 分数出来后，面对几百所大学完全不知道选哪个 |
| 核心需求 | 想知道去了这所大学，日常生活是什么体验 |
| 决策因素 | 宿舍条件 > 交通便利 > 周边商圈 > 校园环境 > 学校排名 |

**用户内心独白：**
> "分数我能查到，排名我能看到，但我想知道的是——这个大学宿舍有没有空调？附近有没有商场？地铁站远不远？"

---

## 三、核心场景

### 场景1：出分后选学校
> 小明考了580分，打开网站输入分数，看到冲-稳-保三档推荐。他点进一所"稳妥"的大学，看到：
> - 宿舍4人间，有空调有独卫，住宿费1200/年
> - 地铁3号线直达，到市中心30分钟
> - 校门口就是大学城商业街，奶茶店、电影院都有
> - "这学校不错，加到我的备选里。"

### 场景2：对比两所大学
> 小红在A大学和B大学之间犹豫，她分别查看了两所大学的校园生活信息：
> - A大学：宿舍6人间没空调，但离市区近，交通方便
> - B大学：宿舍4人间有空调，但在郊区，去市区要1小时
> - "我怕热，选B。"

### 场景3：分享给朋友
> 小刚觉得这个工具很好用，把链接分享到班级群："你们也看看，比那些只有分数线的网站有用多了。"

## 四、功能规划

### 已上线（v1.0）
| 功能 | 状态 | 说明 |
|------|------|------|
| 智能推荐 | ✅ | 输入分数，冲-稳-保三档推荐 |
| 搜索大学 | ✅ | 按名称、省份、类型筛选 |
| AI 校园分析 | ✅ | 宿舍、食堂、交通、周边（需配置 API Key） |
| 收藏大学 | ✅ | 收藏感兴趣的学校 |

### 待优化（v1.1）
| 功能 | 优先级 | 说明 |
|------|--------|------|

## 五、页面结构（当前）

```
首页
├── 智能推荐（Tab 1）
│   ├── 输入：省份 / 科类 / 分数
│   └── 结果：冲-稳-保三档大学卡片
│       └── 点击 → 大学详情弹窗
│           ├── 基本信息（省份、类型、标签）
│           ├── 校园生活（AI 分析：宿舍/食堂/环境）
│           ├── 交通出行（AI 分析：地铁/商圈）
│           └── 录取数据
│
└── 找大学（Tab 2）
    ├── 搜索框 + 筛选（省份/类型）
    └── 大学列表卡片
        └── 点击 → 大学详情弹窗（同上）
```

## 六、商业模式

### 阶段一：免费获客（现在）
- 所有功能免费使用
- 通过口碑传播获取用户
- 目标：高考季（6-7月）获取第一批种子用户

### 阶段二：增值服务（用户量1000+）
| 付费功能 | 定价 | 说明 |
|----------|------|------|
| AI 深度分析 | 免费用户每天3次，付费无限 | 解锁更多 AI 查询次数 |
| 志愿填报报告 | 9.9元/份 | 生成完整的志愿填报方案 PDF |
| 专家一对一咨询 | 99元/次 | 真人老师帮你分析 |

### 阶段三：平台化（用户量10000+）
- 学长学姐入驻，写评价赚收益
- 高校合作，官方发布校园信息
- 广告收入（教育机构、培训机构）

## 八、竞品分析

| 产品 | 优势 | 劣势 | 我们的机会 |
|------|------|------|-----------|
| 掌上高考 | 数据全、权威 | 只有分数线，没有校园生活信息 | 做他们没做的事 |
| 百度AI志愿 | 百度流量大 | 推荐不精准，没有差异化 | 专注校园生活体验 |
| 小红书/贴吧 | 有真实评价 | 信息零散，需要自己翻 | AI 整合，一键查看 |
| 各高校官网 | 官方信息 | 分散，不方便对比 | 一站式对比 |

**我们的护城河：** AI 校园生活分析 + 用户真实评价的结合，这是目前没有任何产品在做的。

## 十、风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| AI 信息不准确 | 用户信任下降 | 标注"AI分析仅供参考"，引入用户评价修正 |
| API 成本高 | 运营压力 | 限制免费次数，付费解锁 |
| 竞品抄袭 | 失去差异化 | 快速迭代，建立用户评价体系形成壁垒 |
| 高考季后用户骤降 | DAU 下滑 | 扩展到考研择校、留学择校 |

## 总结

这个产品的核心价值是**帮高考生了解大学的真实生活**，而不是重复做分数匹配。

短期目标：高考季获取第一批用户，验证产品价值。
长期目标：成为高考生择校决策的第一入口。
